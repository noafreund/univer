# מערכת ניהול מזכירות – המשרד

מערכת שמחליפה את קובץ האקסל: אנשי קשר, יומן שיחות, ובהמשך גם מעקב פגישות, העברת משמרת ועוד.
המערכת רצה **על המחשב במשרד** ונפתחת בדפדפן (Chrome / Edge). המידע לא עולה לאינטרנט.

---

## התקנה (פעם אחת בלבד)

1. **להתקין Node.js:** להיכנס ל-https://nodejs.org, להוריד את הגרסה שכתוב עליה **LTS**, ולהתקין (Next, Next, Finish).
2. **להוריד את התיקייה `office-secretary`** למחשב, למשל ל-`C:\office-secretary`.
3. **ללחוץ פעמיים על `setup.bat`.** ייפתח חלון שחור שיעבוד כמה דקות. בסוף יופיע `Done!`.
   - צריך לעשות את זה שוב רק כשמקבלים גרסה חדשה של המערכת.

## הפעלה (כל יום)

- **ללחוץ פעמיים על `start.bat`.** הדפדפן ייפתח לבד על המערכת.
- את החלון השחור **לא סוגרים** (אפשר למזער אותו). סגירה שלו = כיבוי המערכת.
- הכתובת בדפדפן: `http://localhost:3000` (כדאי לשמור כמועדף).

## כניסה ראשונה

בפעם הראשונה המערכת תבקש:
- שמות שתי המזכירות (בוקר – זוהי, וצהריים),
- סיסמה משותפת אחת לכניסה.

אחר כך בכל כניסה בוחרים "מי את" ומקלידים את הסיסמה. המחשב זוכר את הכניסה ל-30 יום.
כפתור **"החלפה ל..."** בצד מחליף משתמשת בלי להקליד סיסמה שוב.

## כניסה מהנייד או ממחשב אחר במשרד

כשהמערכת פועלת, אפשר להיכנס אליה מכל מכשיר שמחובר **לאותה רשת Wi-Fi של המשרד**:
1. במחשב שבו המערכת רצה: ללחוץ על התחל ← להקליד `cmd` ← Enter ← להקליד `ipconfig` ← Enter.
2. לחפש שורה `IPv4 Address`, למשל `192.168.1.25`.
3. בנייד לפתוח בדפדפן: `http://192.168.1.25:3000` (עם המספר שמצאת).
   - אם זה לא נפתח: ייתכן ש-Windows שאל בפעם הראשונה "לאפשר גישה ברשת?" – צריך לסמן **רשתות פרטיות** ולאשר.

## איפה המידע נשמר

הכול נשמר בקובץ אחד: `office-secretary\data\office.db`.
- **לא למחוק** את תיקיית `data`!
- גיבוי אוטומטי יומי וייצוא לאקסל יתווספו בשלב 3.
- (מתקדם) אפשר לשנות את מיקום התיקייה: ליצור קובץ `.env.local` עם השורה `OFFICE_DATA_DIR=D:\office-data`.

## מה יש בשלב 1

| מסך | מה עושים בו |
|---|---|
| **היום שלי** | תיעוד שיחה מהיר + השיחות של היום + מונים |
| **יומן שיחות** | תיעוד שיחה, כפתור **א"מ** בלחיצה אחת, סינון לפי תאריכים / ארגון / תוצאה / פתוח-סגור, עריכה ומחיקה |
| **אנשי קשר** | רשימה, כרטיס איש קשר עם כל היסטוריית השיחות, כמה טלפונים ומיילים עם תוויות, קישור למזכירה / מנהלת הלשכה, **התראה על כפילות** |
| **ארגונים** | רשימה, הצעות לאיחוד כפילויות ("עמק חפר" / "מ.א. עמק חפר"), איחוד ידני |
| **חיפוש** (למעלה) | לפי שם, ארגון, טלפון (גם בלי 0 בהתחלה), מייל, או מילה מהפירוט |

### טיפים
- **שיחה תוך שניות:** מקלידים כמה אותיות מהשם או מהמועצה ← Enter ← לוחצים תוצאה ← "שמירת שיחה".
  התאריך והשעה מתמלאים לבד.
- **אין מענה:** בוחרים איש קשר ולוחצים **📵 א"מ** – וזהו. ברשימת השיחות יש גם כפתור **+א"מ** בכל שורה (ניסיתי שוב, שוב אין מענה).
- **איש קשר חדש תוך כדי שיחה:** מקלידים שם שלא קיים ← "הוספת ... כאיש קשר חדש" ← ממלאים ארגון.
- לחיצה על **פתוח / סגור** בטבלה מחליפה את המצב.
